## 3. Investigate Markdown to PDF Conversion

**Goal:** Convert generated Markdown files to PDF using Python (without external web tools).

**Potential libraries to evaluate:**
- `markdown` + `weasyprint` - HTML intermediate, good CSS support
- `markdown2pdf` or similar wrapper libraries
- `pypandoc` - Uses Pandoc (requires external binary)
- `fpdf2` with `markdown` - More control, more manual work
- `mkdocs` with PDF export plugins - May be overkill

**Acceptance criteria:**
- Pure Python solution preferred, or minimal external dependencies
- Preserve basic formatting (headers, lists, bold/italic)
- Handle images/embeddings if present
- Command to run conversion: `uv run convert.py input.md output.pdf`

**Files to create:**
- `app/util/pdf.py` - PDF conversion utility
- `convert.py` or add to `main.py` as additional command
